# Homepage runtime images

This directory contains exactly one browser-ready WebP for each live homepage
artwork. The reviewable PNG sources remain in `../homepage-concept/`.

The files are generated by `tools/build_homepage_runtime.py`. That script uses
premultiplied-alpha resizing for transparent sources, lossless WebP for the three
observation plates with raster text, and carefully tuned lossy WebP settings for
the remaining artwork. It also exports the site favicon from the preserved stone
N source.

There are intentionally no mobile, `@2x`, fallback, or `srcset` variants here.
