# Security Policy

## Supported versions

The project is pre-release research software. Only the current `master` branch
receives security fixes; no stability or response-time guarantee is offered.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose data,
execute untrusted code, compromise a build, or create a material biological
safety concern. Email [contact@waajacu.com](mailto:contact@waajacu.com) with a
clear description, affected revision, reproduction information, and potential
impact.

We will acknowledge receipt when maintainers are available, investigate before
making details public, and credit reporters who wish to be named. This early
project cannot promise a fixed response deadline.
